Which Tesla Model Y year should I pick?

Tesla does not print a separate owner's manual for each Model Y year. The 2020 to 2024 Model Y owner's manual is one book. The 2025+ North America PDF (cover software 2026.2.8) is a second book. Checked 20 Nov 2026. Both books print the same windshield blades and the same key fob cell. They do not describe the exterior lights the same way, so 2021, 2022, 2023, and 2024 are not separate pages here.

Windshield blades, in both books: driver side 26 inches (650 mm), passenger side 20 inches (500 mm). The connector has to match the blade already on the arm. Neither windshield chapter prints a rear blade length. The accessory key fob takes a CR2032, positive side up. The key card section does not print a coin cell. A phone key uses the phone, not a cell you buy for the car.

Lights: the 2020 to 2024 book says Model Y has LED signature lights along the headlight rim, and it does not print a bulb trade number. The 2025+ book describes a front lightbar and a tail lightbar (the front lightbar line says if equipped) that work as daytime running lights, parking lights, and tail lights. That book also does not print a bulb number. Do not copy the 2020 recall list onto a later car. NHTSA's recalls API, retrieved 20 Nov 2026, returned 24 campaigns for 2020, 23 for 2021, 20 for 2022, 17 for 2023, 5 for 2024, and 3 for 2025. Use the VIN lookup.

Which key fob battery fits a Tesla Model Y?

It depends on the year, and sometimes on which remote is in the car. Open the year page. The short battery line for each year we have checked is in the table on this page.

Which wiper blade fits a Tesla Model Y?

Use the year page. Some manuals print an inch length, and some print only a part number or say the length is not in the book. Do not reuse a length from a different year.

Which bulb fits a Tesla Model Y?

The headlight, brake, and turn rows are on the year page, copied from that year's owner's manual. Trims in the same year can take different lamps.
