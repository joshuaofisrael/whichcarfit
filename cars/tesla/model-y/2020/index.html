2020 to 2024 Model Y wiper and key fob

Owner's manual checked 20 Nov 2026

Direct answer

  • Key fob battery: Accessory key fob: one CR2032, positive side facing up. The key card section does not print a coin cell. A phone key uses the phone.
  • Front wiper: Driver side 26 inches (650 mm). Passenger side 20 inches (500 mm). The replacement blade connector has to match the original blade.
  • Rear wiper: The windshield wiper chapter does not print a rear blade length.
  • Headlight: The lights chapter describes LED signature lights along the headlight rim. It does not print a bulb trade number.
  • Brake light: A brake lamp trade number is not printed in the lights chapter we read.
  • Turn signal: A turn signal trade number is not printed in the lights chapter we read.

Tesla's own manual URL covers model years 2020 through 2024 in one book. This page is that book. 2021, 2022, 2023, and 2024 are not separate pages because the book does not give them a different wiper or key chart. Recalls below are model year 2020 only. The same API returned 23 campaigns for 2021, 20 for 2022, 17 for 2023, and 5 for 2024, retrieved 20 Nov 2026. Look up the VIN.

Confirm every part against the owner's manual and the vehicle itself. This is a guide, not a repair instruction. Lamp packages change by trim, and a later book can change a chart. See the fitment guide for how we read a chart, and the key fob battery hub if you only need the cell.

Frequently asked questions

What battery does the 2020 Tesla Model Y key fob take?

Accessory key fob: one CR2032, positive side facing up. The key card section does not print a coin cell. A phone key uses the phone. Match the remote you hold to the description, because some model years print two different cells.

Which wiper, bulb, and battery fit a 2020 Tesla Model Y?

Battery: Accessory key fob: one CR2032, positive side facing up. The key card section does not print a coin cell. A phone key uses the phone. Front wiper: Driver side 26 inches (650 mm). Passenger side 20 inches (500 mm). The replacement blade connector has to match the original blade. Headlight: The lights chapter describes LED signature lights along the headlight rim. It does not print a bulb trade number. Brake light: A brake lamp trade number is not printed in the lights chapter we read. Turn signal: A turn signal trade number is not printed in the lights chapter we read.

Where do I find the tire size and the bulb chart for a 2020 Tesla Model Y?

Tire size and cold pressure are on the driver's door jamb label. The bulb types in the table on this page are taken from the owner's manual cited below, not from that label. If the manual lists more than one lamp package, match the row to the lamps on your vehicle.

Where do I look up recalls on a 2020 Tesla Model Y?

Go to https://www.nhtsa.gov/recalls and enter the VIN from the driver's door jamb. The campaigns listed on this page are what NHTSA's public recalls API returned for this model year on 20 Nov 2026.
