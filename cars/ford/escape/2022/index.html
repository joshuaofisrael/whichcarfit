2022 Ford Escape key fob battery, wiper size, bulb size, and common problems

Owner's manual checked 16 Nov 2026

Direct answer

  • Key fob battery: The manual prints both a CR2032 remote and a CR2450 remote, each described as one coin type 3 volt lithium battery.
  • Front wiper: Motorcraft WW-2502 driver side and WW-2051 passenger side. No inch length is printed.
  • Rear wiper: Motorcraft WW-1112 for the rear window.
  • Headlight: Base headlamp low beam H9. Base headlamp high beam HB3. Optional headlamp is LED. Base fog lamp H8. Optional fog lamp is LED.
  • Brake light: Tail and brake lamp: LED. High mount brake lamp: LED. The chart says to see a dealer for lamps marked that way.
  • Turn signal: Base headlamp turn: T20 amber. Rear turn lamp: T20 amber. Base headlamp side marker: LED. Rear side marker: W5W.

Confirm every part against the owner's manual and the vehicle itself. This is a guide, not a repair instruction. Lamp packages change by trim, and a later book can change a chart.

Frequently asked questions

What battery does the 2022 Ford Escape key fob take?

The manual prints both a CR2032 remote and a CR2450 remote, each described as one coin type 3 volt lithium battery. Match the remote you hold to the description, because some model years print two different cells.

Where do I find the tire size and the bulb chart for a 2022 Ford Escape?

Tire size and cold pressure are on the driver's door jamb label. The bulb types in the table on this page are taken from the owner's manual cited below, not from that label. If the manual lists more than one lamp package, match the row to the lamps on your vehicle.

Where do I look up recalls on a 2022 Ford Escape?

Go to https://www.nhtsa.gov/recalls and enter the VIN from the driver's door jamb. The campaigns listed on this page are what NHTSA's public recalls API returned for this model year on 16 Nov 2026.
