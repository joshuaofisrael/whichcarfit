How a page is built

We open that year's owner's manual and copy the key fob cell, the wiper part or length, and the bulb chart, with the manual linked on the page. Recalls and complaint counts come from NHTSA's public API for that model year. If the manual does not print a figure, the page says so. Sources and methods.

Which part fits my car?

Which key fob battery fits my car?

Choose the make, model, and year in the picker above. The year page quotes the cell the owner's manual prints. Some cars have two remotes and two different cells.

Which wiper blade fits my car?

The year page lists the front and rear wiper line from that year's manual. Use an inch length only when the manual prints one.

Which bulb fits my car?

The year page lists the headlight, brake light, and turn signal lines from that year's bulb chart. The door jamb label is for tires, not bulbs.
