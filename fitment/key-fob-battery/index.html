Key fob battery by vehicle

What battery the key fob takes, from the owner's manual. Open the year page for the full chart and the manual link. A figure from one year is not a figure for the next year.

  • 2018 Ford F-150: Key fob battery: Integrated keyhead transmitter: one CR2032, or equivalent. Intelligent Access key: one CR2450, or equivalent.
  • 2020 Ford F-150: Key fob battery: Integrated keyhead transmitter: one CR2032, or equivalent. Intelligent Access key: one CR2450, or equivalent.
  • 2022 Ford F-150: Key fob battery: One coin type 3 volt lithium battery. The manual prints CR2032 for one remote and CR2450 for the other.
  • 2020 Ford Escape: Key fob battery: Integrated keyhead transmitter: one CR2032, or equivalent. The intelligent access remote uses one CR2450, or equivalent.
  • 2022 Ford Escape: Key fob battery: The manual prints both a CR2032 remote and a CR2450 remote, each described as one coin type 3 volt lithium battery.
  • 2023 Ford Ranger: Key fob battery: A coin cell type was not printed in the remote section of the text we searched. Do not guess a size. Open the Keys and Remote Controls chapter in this edition.
  • 2020 Ford Fusion: Key fob battery: A coin cell type was not printed in the passages we searched. Open the remote battery steps in this edition before you buy a cell.
  • 2020 Ford Mustang: Key fob battery: One CR2450, or equivalent.
  • 2020 Ford Expedition: Key fob battery: Integrated keyhead transmitter: one CR2032, or equivalent. Intelligent Access key: one CR2450, or equivalent.
  • 2019 Ford Edge: Key fob battery: A coin cell type was not printed in the passages we searched.
  • 2020 Ford Edge: Key fob battery: Intelligent Access key: one CR2450, or equivalent.
  • 2020 Lincoln Nautilus: Key fob battery: One CR2450, or equivalent.
  • 2021 Ford E-Series: Key fob battery: One CR2032, or equivalent.
  • 2021 Ford Police Interceptor Utility: Key fob battery: One CR2032, or equivalent.
  • 2020 Jeep Wrangler: Key fob battery: CR2450.
  • 2024 Jeep Wrangler: Key fob battery: The recommended replacement battery is CR2450.
  • 2026 Jeep Wrangler: Key fob battery: The recommended replacement battery is CR2450.
  • 2023 Jeep Cherokee: Key fob battery: One CR2032.
  • 2025 Jeep Grand Cherokee: Key fob battery: One CR2450.
  • 2020 Ram 1500: Key fob battery: One CR2450.
  • 2023 Ram 1500: Key fob battery: One CR2450.
  • 2026 Ram 1500: Key fob battery: One CR2450.
  • 2023 Dodge Durango: Key fob battery: One CR2032.
  • 2018 Honda Civic: Key fob battery: Master keys with a remote transmitter: CR1620. Smart entry remote: CR2032. The manual marks each one as not available on all models. Page 562.
  • 2025 Honda CR-V: Key fob battery: CR2032, in Remote Transmitter Care.
  • 2024 Toyota Grand Highlander: Key fob battery: Lithium battery CR2450.
  • 2025 Toyota Corolla Hybrid: Key fob battery: Lithium battery CR2032.
  • 2024 Toyota Corolla Cross Hybrid: Key fob battery: Lithium battery CR2450.
